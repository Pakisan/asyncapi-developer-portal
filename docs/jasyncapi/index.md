# JAsyncAPI

**Free and open source (Apache-2.0).** A JVM library to read, create and write AsyncAPI documents from Java and Kotlin. It is used by projects such as Springwolf, the Quarkus AsyncAPI extension and Specmatic.

## What is included

- AsyncAPI 2.0.0, 2.6.0 and 3.0.0
- 19 protocol bindings: AMQP, AMQP 1.0, Anypoint MQ, Google Pub/Sub, HTTP, IBM MQ, JMS, Kafka, Mercure, MQTT, MQTT 5, NATS, Pulsar, Redis, SNS, Solace, SQS, STOMP and WebSockets
- Multi-format schemas: Avro, JSON Schema, OpenAPI 3.0 and XML
- All security scheme types
- Java 8 and newer

## Get it

Available on [Maven Central](https://central.sonatype.com/artifact/com.asyncapi/asyncapi-core) as `com.asyncapi:asyncapi-core`. Source and issues on [GitHub](https://github.com/asyncapi/jasyncapi).
