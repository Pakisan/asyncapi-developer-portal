# Solace Channel Binding v0.1.0

The Solace channel binding `v0.1.0` is a placeholder for defining a channel as a Solace topic.

## Overview

As of this version, the binding does not contain any properties. Its presence is for informational purposes only.

## Channel Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `bindingVersion` | string | No | Binding version (defaults to `0.1.0`). |
