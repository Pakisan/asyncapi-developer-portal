# Solace Operation Binding v0.1.0

The Solace operation binding `v0.1.0` is a placeholder for defining properties specific to a Solace operation.

## Overview

As of this version, the binding does not contain any properties. Its presence on an operation is for informational purposes only.

## Operation Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `bindingVersion` | string | No | Binding version (defaults to `0.1.0`). |
