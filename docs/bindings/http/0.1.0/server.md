# HTTP Server Binding v0.1.0

The HTTP server binding `v0.1.0` specifies that an AsyncAPI server corresponds to an HTTP server.

## Overview

As of this version, the binding is a placeholder and has no configurable properties.

## Server Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `bindingVersion` | string | No | Binding version (defaults to `0.1.0`). |
