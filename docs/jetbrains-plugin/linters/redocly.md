# 🔵 Redocly Validation

![](https://plugins.jetbrains.com/files/15673/62207-page/dc57268d-0324-478a-ba5f-dd5f04b336b1)

Redocly is the industry standard for enforcing API style rules, structure, and documentation quality - now fully integrated into your IDE workflow.

What you get:
- ⚡ Instant validation on save or while typing
- 📘 Support for Redocly config files (redocly.yaml, custom rulesets, style guides)
- 🧠 Smart error highlighting directly in the editor
- 📝 Support for .redoclyignore with full .gitignore syntax
- 🔁 Manual lint runs when you want deeper inspection

Perfect for teams already using Redocly’s style guide or publishing pipelines - the plugin brings everything directly into JetBrains IDEs so developers get feedback early, not after CI fails
