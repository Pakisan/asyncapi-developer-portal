# 🟣 Spectral Validation

![](https://plugins.jetbrains.com/files/15673/62207-page/138e84b8-0786-44c8-b89a-a83e8d64e792)

Spectral is the flexible, JSON/YAML-first rules engine used across the API industry.

Now, you can apply your Spectral rulesets to AsyncAPI files instantly inside your IDE.

What you get:
- 🧩 Support for custom Spectral rulesets (.spectral.yaml, shared configs, overrides)
- ⚠️ Real-time linting and precise inline error messages
- 🚫 .spectralignore support to exclude files or entire folders
- 🔧 Manual Spectral runs when you want full validation output
- 🌐 Works out of the box with AsyncAPI’s official rulesets

Spectral gives you full control over quality checks - from naming conventions to schema structures - and the plugin enforces those rules automatically as you type
