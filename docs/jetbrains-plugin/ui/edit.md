# New way to edit

![](/jetbrains-plugin/features/preview.png)

Working with a large AsyncAPI file in plain text can be painful.

You scroll… and scroll… and scroll… just to find channel which you want to update

Now you can edit your entire specification at a glance - without opening a single line of YAML or JSON.

## 🌳 A Familiar Tree Navigation

Just like exploring a project structure, all AsyncAPI elements are now organized into a clean, intuitive tree:
- Servers
- Channels
- Operations
- Messages
- Components
- Security
- Bindings

Everything is visible, structured, and easy to edit with a click.

## ⚡ A massive time-saver

Instead of scrolling through a 3,000-line file:

1. Open the UI
2. Browse the tree
3. Inspect elements to edit instantly

## 🧠 Designed for clarity

AsyncAPI specs can get complex. The native UI makes them simple.

No more searching

No more scrolling

Just open and edit exactly what your AsyncAPI specification contains
