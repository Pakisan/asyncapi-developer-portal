# AsyncAPI Language Server

**Status: in development.** AsyncAPI support for editors outside the JetBrains family, so writing AsyncAPI feels the same in every editor.

## What you get

- Errors and warnings highlighted as you type
- Context-aware completion
- Quick documentation on hover
- Planned editors: Visual Studio Code, Zed and Sublime Text
- AsyncAPI 3.0 first, then 2.6

Extra paid capabilities are planned: server variables and channel parameters completion, and validation of messages against the schemas declared in channels and operations.

## Working in a JetBrains IDE?

The [AsyncAPI plugin for JetBrains IDEs](/jetbrains-plugin/) is available today, with a free core.
